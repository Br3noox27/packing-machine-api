# packing-machines-api

API para registrar e analisar as paradas das máquinas de embalagem de uma fábrica.

> **Status: em construção.** Estou aprendendo Python e escrevendo este projeto do zero, passo a passo.

## Problema

Trabalho com manutenção de 12 máquinas. As paradas hoje ficam em planilha, difícil de consultar e de conferir se seguem a regra de conformidade. Quero um sistema que registre cada parada e diga quanto tempo foi perdido e por qual causa.

## Plano

- [ ] v0: funções em Python (total parado, maior parada, conformidade)
- [ ] v1: dados guardados em PostgreSQL
- [ ] v2: API com FastAPI (listar máquinas, registrar parada, relatório)
- [ ] v3: testes com pytest
- [ ] v4: Docker e deploy
